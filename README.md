IoT Weather Station

A compact IoT weather station built around an ESP32, a DHT22 temperature and humidity sensor, and an integrated OLED display.

The project includes:

- Embedded software: C++/Arduino firmware.
- Weather monitoring: Local temperature and humidity measurements.
- Online weather data: Weather information retrieved from an external API.
- Electronic design: Electronic schematic and wiring documentation.
- Mechanical design: Custom 3D-printed PETG enclosure designed with SolidWorks.

This project combines embedded programming, electronics, and mechanical design into a functional weather station.
